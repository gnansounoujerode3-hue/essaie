# Voix de démonstration

`vo_demo.mp3` est une voix off synthétisée pour l'exemple « 3 erreurs qui tuent tes vues ». Elle sert à tester le mixage, le ducking et l'alignement des sous-titres (`sf align`). Remplacez-la par une voix enregistrée ou générée pour votre marque avant publication et vérifiez les droits d'utilisation applicables.
