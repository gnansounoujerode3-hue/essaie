# CTA-Converter

## Principe

Une demande par Short. Le cerveau ne peut pas exécuter deux actions
simultanées (« like + abonne + commente ») : il en exécute une, ou aucune.
Choisir **une** action correspondant à l'objectif du Short.

| Objectif du Short | CTA |
| --- | --- |
| Notoriété (vues) | « Partage à quelqu'un qui en a besoin » |
| Abonnés | « Abonne-toi : 1 astuce par jour » |
| Communauté | « Dis-moi en commentaire : tu vas le faire ? » |
| Ventes | « Le lien est en bio — il reste 12 pièces » |
| Fidélisation | « Enregistre cette vidéo pour la revoir » |

## Le CTA doit être une promesse, pas un ordre

| Faible | Fort |
| --- | --- |
| « Abonne-toi ! » | « Abonne-toi : 1 astuce par jour, 20 s. » |
| « Like la vidéo » | « Enregistre-la, tu vas en avoir besoin au montage » |
| « Commente » | « Quel montage te prend le plus de temps ? » |

## Double canal : voix + écran

- **Voix** : la phrase complète (« Abonne-toi si tu veux la suite »).
- **Écran** : 2 à 4 mots en gros (« ABONNE-TOI »), couleur accent.

Un CTA uniquement visuel est ignoré (le spectateur regarde l'image, pas le
texte). Un CTA uniquement audible est ignoré (70 % sans son). **Les deux
ensemble**, c'est le maximum d'impact.

## Placement

- **Fenêtre** : les **3 dernières secondes** (pas avant, pas après).
- **Durée à l'écran** : 2,0 à 3,5 s — le temps de lire ET de réagir.
- **Contraste** : fond sombre ou vignette derrière le texte pour qu'il se
  détache du plan.
- **Ne jamais coller le CTA sur le bas de l'image** (boutons UI).

## Le CTA circulaire

Un CTA qui **termine** casse la boucle ; un CTA qui **prolonge** la renforce.

```
✗ "Abonne-toi, et à bientôt !"      → son de fin
✓ "Le 2ᵉ conseil est encore pire."   → le spectateur reste
```

## Variantes à tester (A/B)

1. **Action** : « Abonne-toi » (direct, faible rétention mais fort taux de
   conversion si la promesse est claire).
2. **Curiosité** : « Le 2ᵉ conseil est encore pire » (meilleure rétention,
   plus faible conversion).
3. **Paucité** : « Je ne poste que ça le lundi » (fort si l'audience est
   fidèle, faible sinon).
4. **Question** : « Tu vas tester le 1 ou le 3 ? » (booste les commentaires,
   donc l'algorithme).

Tester **un seul élément à la fois** (le hook, ou le CTA, ou la durée) —
sinon on n'apprend rien.

## Anti-patterns

| Anti-pattern | Pourquoi ça échoue |
| --- | --- |
| 3 actions demandées | Aucune n'est exécutée |
| « Like et abonne et commente » | Dilue la demande |
| CTA hors des 3 dernières secondes | Le spectateur est déjà parti |
| CTA sans promesse | Aucune raison d'obéir |
| « N'oublie pas de… » | Formulation négative, faible |
| Lien en description uniquement | 90 % ne lisent pas la description |
